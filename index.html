Usage

Write or paste a formula into the editor, select a mode, and click Run (or press Shift + Enter).

Permalinks: Every analysis synchronizes the formula and mode directly into the browser URL hash so you can share it directly.

Drag & Drop: Drag any local text file directly onto the formula input area to load and execute it.

Analysis Modes

  • Validity Check: Verifies if the formula is valid (a tautology satisfied under all possible variable assignments).
  • Satisfiability Check: Tests whether there exists at least one satisfying assignment using PicoSAT.
  • Truth Table: Computes all 2n variable evaluations and displays model counts.
  • QBF Satisfiability: Evaluates quantified formulas with universal # (∀) and existential ? (∃) quantifiers using DepQBF.

Syntax (EBNF)

expr    ::= iff
iff     ::= implies { '<->' implies }
implies ::= or [ '->' or | '<-' or ]
or      ::= xor { ('|' | '/') xor }
xor     ::= and { '^' and }
and     ::= not { '&' not }
not     ::= basic | '!' not | '~' not
basic   ::= var | const | '(' expr ')'
const   ::= 'true' | 'false' | '1' | '0'
var: letters, digits, and _ . [ ] $ @ (must not end with -).
Extended operators: XOR (^), constants (true, false, 1, 0), and / for OR.
